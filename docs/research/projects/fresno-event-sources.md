## November 6 integration

The user authorized trials of the three recommended sources. All three are registered in the normal venue workflow. Live preflight returned 145 physical timed library events, 20 public arts events and 10 Philharmonic performances with zero fetch errors. The full collection returned 144 library events after one preflight event’s start had passed. The library collector uses a 30-day window and verified Fresno/Clovis branch addresses. Public arts uses two 30-day windows and excludes online, internal-only, all-day and multi-day ranges. Philharmonic uses a 180-day window and distinct IDs for each performance. Three records correctly matched existing publications: the Briggs recital and both Elgar performances. All 174 collected occurrences have verified map coordinates and distinct provider IDs. The unverified Barn venue remains deferred. Twelve arts records need AI enrichment; two of them also conflict on venue/time. Three library volunteer shifts need an attendance eligibility check. Source evidence, the model-credit interruption and exact test hashes are recorded in [the source ledger](../../operations/2026-11-06-promotion-review/SOURCE_LEDGER.json) and [run report](../../operations/2026-11-06-promotion-review/REPORT.md).
